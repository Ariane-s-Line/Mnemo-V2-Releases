# MNemo Firmware Releases

This repository contains pre-built firmware binaries for the **MNemo V2** cave surveying instrument.

## How to install

1. Download the latest `.uf2` file from the [Releases](../../releases) page.
2. Put the device into bootloader mode using one of two methods:
   - **Via the menu** — select the firmware update entry in the device menu.
   - **Via magnet** — bring the magnet close to the device twice within 2 seconds.
3. A `RPI-RP2` drive will appear on your computer.
4. Drag and drop the `.uf2` file onto that drive.
5. The device will reboot automatically with the new firmware.


## Support Policy

Only the two latest firmware releases are supported. Older versions are provided for reference only and will not receive bug fixes or updates.
